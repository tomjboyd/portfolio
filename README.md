# Thomas Boyd - Portfolio

My simple, SEO-friendly, performant and accessible personal portfolio.

## Stack

- **[Astro](https://astro.build)** - ships static HTML (great for SEO, fast, no client framework needed).
- **[Tailwind CSS v4](https://tailwindcss.com)** - styling, via the `@tailwindcss/vite` plugin.
- **[shadcn/ui](https://ui.shadcn.com)** - the component source lives in `src/components/ui/` so it's fully reviewable and editable.

## Run it

```bash
npm install
npm run dev
npm run build
npm run preview
```

Or use your preferred package manager, I'm partial to pnpm.

## Usage

Feel free to copy the repo and re-implement for your own profile. There's a solid, simple structure in place to spin up a straight foward but effective portfolio site.
